این نسخه بر پایه پروژه Capacitor بازیابی‌شده ساخته شده است. رابط برنامه فارسی و راست‌چین است و برای تبدیل به APK اندروید آماده‌سازی شده است.

ماژول‌های ۲۱ تا ۳۱ در این نسخه به شکل فرم‌ها و دفاتر ثبت ساختاریافته اضافه شده‌اند؛ اتصال خودکار بین همه سوابق، موتور تأیید صلاحیت، گردش‌کار امضای دیجیتال و کنترل دسترسی نقش‌محور هنوز پیاده‌سازی نشده است. فرم «کنترل پیش از انتصاب» دستی است و نباید به‌تنهایی مبنای مجاز کردن نیروی انسانی قرار گیرد.

### زیرساخت
- اجرای آفلاین پس از نصب و بسته‌بندی منابع برنامه
- SQLite محلی در نسخه Native اندروید
- حفظ وضعیت اصلی برنامه برای سازگاری با داده‌های نسخه قبلی
- نمایه‌سازی رکوردهای ماژول‌ها در `module_records`
- به‌روزرسانی فقط ماژول‌های تغییرکرده در ذخیره‌های بعدی
- انتقال اولیه داده‌های `localStorage` نسخه قدیمی به SQLite
- پشتیبان‌گیری JSON و بازیابی با کنترل ساختار و تلاش برای حفظ داده قبلی در صورت خطا
- خروجی و اشتراک گزارش HTML و چاپ/PDF از طریق قابلیت چاپ سیستم
- تاریخ محلی گوشی برای محاسبات روز جاری

## ساخت APK در ویندوز

پیش‌نیازها:
- Node.js نسخه ۲۰ یا بالاتر و npm
- Android Studio و Android SDK
- JDK سازگار با Android Gradle Plugin پروژه تولیدشده (معمولاً JDK 17 برای زنجیره‌های جدید)
- اینترنت برای دریافت وابستگی‌های npm و Gradle در اولین ساخت

مراحل:
1. ZIP را استخراج کنید.
2. مطمئن شوید Android Studio و Android SDK نصب شده‌اند.
3. فایل `build-apk.bat` را اجرا کنید.
4. خروجی Debug در مسیر زیر ساخته می‌شود:

```text
android\app\build\outputs\apk\debug\app-debug.apk
```

برای ساخت دستی:

```bat
npm install
npm run check
npm run build
npx cap add android
npx cap sync android
cd android
gradlew.bat assembleDebug
```

اگر پوشه `android` قبلاً ساخته شده باشد، دستور `npx cap add android` را دوباره اجرا نکنید؛ فقط `npx cap sync android` و سپس Gradle را اجرا کنید.

## سازگاری

پیکربندی هدف، Android 14 و گوشی POCO X5 5G است؛ اما سازگاری نهایی باید با ساخت APK و نصب روی همان گوشی تأیید شود. پوشه Native اندروید داخل ZIP نیست و توسط Capacitor در اولین ساخت ایجاد می‌شود.

## هشدار امنیتی مهم

- دیتابیس SQLite فعلی با تنظیم `no-encryption` ساخته می‌شود.
- فایل‌های پشتیبان JSON رمزنگاری نمی‌شوند.
- PIN موجود در رابط، رمزنگاری یا احراز هویت امن نیست و با دسترسی فنی به دستگاه قابل دور زدن است.
- اطلاعات تشخیصی، نتایج آزمایش، پرونده درمانی، کد ملی یا یادداشت‌های پزشکی محرمانه را در این نسخه وارد نکنید.
- تا پیش از افزودن رمزنگاری پایگاه داده و پشتیبان، مدیریت کلید امن، احراز هویت واقعی، سطح دسترسی نقش‌محور و ممیزی تغییرات، این نسخه برای نگهداری اطلاعات حساس یا تصمیم‌گیری ایمنی/پزشکی عملیاتی تأیید نشده است.

## محدودیت‌های شناخته‌شده

- ذخیره‌سازی ساختاریافته فعلاً یک نمایه از وضعیت JSON اصلی است؛ همه فرم‌ها مستقیماً به جداول رابطه‌ای مستقل متصل نیستند.
- همگام‌سازی چنددستگاهی فعال نیست؛ `sync_queue` فقط طرح اولیه است.
- ثبت ورود/خروج و کنترل انتصاب دستی است و کنترل دسترسی واقعی یا جلوگیری قطعی از ورود فرد فاقد صلاحیت ندارد.
- حدود مجاز آلاینده‌ها باید از استاندارد معتبر و متناسب با روش نمونه‌برداری تعیین شوند؛ مقایسه خودکار واحدها وجود ندارد.
- محاسبه RULA/REBA، اعتبارسنجی مدارک، تقویم شمسی، اعلان زمان‌بندی‌شده، امضای دیجیتال و پیوست امن هنوز تکمیل نشده‌اند.
- محتوای کمک‌های اولیه، فرم‌های رسمی، محاسبات مهلت قانونی و دسته‌بندی‌های فنی باید توسط مسئول HSE و مراجع ذی‌صلاح بازبینی شوند.

## آزمون‌های انجام‌شده در این بسته

- بررسی نحوی فایل‌های JavaScript با Node.js
- بررسی همسان بودن فهرست ماژول‌های برنامه و SQLite
- آزمون ایستا برای حضور فرم‌ها، صفحات و کلیدهای پشتیبان ماژول‌ها

در محیط آماده‌سازی این فایل، دریافت npm به علت نبود دسترسی شبکه به registry.npmjs.org ممکن نشد و Android SDK/Gradle نیز در دسترس نبود؛ بنابراین `vite build`، ساخت APK و تست نصب روی گوشی انجام‌شده اعلام نمی‌شوند. این ZIP پروژه اصلاح‌شده است، نه APK تأییدشده.
